# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting: open this
repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue, pull request
or discussion for a security problem.

Include what is affected (self-hosted server, Docker image or desktop app, and the version or commit), how to
reproduce it, and the impact you expect.

## Scope

The security model is described in the README: the hosted setup's login and session handling under
[Hosted setup](README.md#hosted-setup-postgres--password), and the desktop app's hardening under
[Security model](README.md#security-model).
